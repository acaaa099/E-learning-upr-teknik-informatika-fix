# Backend

Folder ini disiapkan untuk source code backend aplikasi E-Learning Platform.

## Rencana Penggunaan
Backend akan digunakan untuk:
- autentikasi pengguna
- manajemen data materi
- pengelolaan tugas dan kuis
- koneksi ke database
- penyediaan API untuk frontend
