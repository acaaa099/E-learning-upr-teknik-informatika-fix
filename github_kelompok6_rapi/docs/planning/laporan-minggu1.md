# Laporan Tugas Minggu 1

## Tema Proyek
E-Learning Platform

## Ringkasan
Dokumen ini berisi ringkasan perencanaan arsitektur cloud menggunakan Microsoft Azure untuk mendukung platform e-learning berbasis web yang skalabel dan mudah dikelola.

## Komponen Utama
- Azure Front Door
- Azure Load Balancer
- Azure Virtual Machine (2 instance)
- Azure Database for MySQL
- Azure VNet + NSG
- Public IP + DNS Zone
- Azure IAM (RBAC)
- Azure Monitor + Log Analytics

Minggu 1 selesai pada tahap perencanaan dan penyusunan arsitektur.
